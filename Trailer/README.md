# CRATER — tráiler

Animación en JavaScript (canvas 2D + WebAudio, sin dependencias) que presenta la estética y las mecánicas del juego en ~1:33.

Abrir `index.html` en un navegador y tocar **Ver tráiler** (el sonido necesita ese clic).
Controles: `Espacio` pausa · `R` reinicia · `M` silencia.

Secuencia: el óculo → se enciende la linterna → título → CUERPO (anclas y puente de luz) →
HUECO (la reja cede) → RASTRO (la escritura que queda al apagar) → adaptación a la oscuridad →
la lente → montaje → cierre.

Colores, conos, alcances, demora de cambio de filtro, retención del rastro y alineación de la lente
salen de los valores de `Assets/Filtro_*.asset` y `Assets/Scripts`.
