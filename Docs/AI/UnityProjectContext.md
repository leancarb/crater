# CRÁTER — contexto de esta copia

Actualizado el 2026-10-06. Proyecto independiente, sin directorio `.git`.

- Unity 6000.3.23f1, URP 17.3.0, Input System 1.20.0. Juego local en primera persona, sin salto.
- La única escena de build es `Assets/Scenes/CraterVerticalSlice.unity`.
- `ConstructorCrater` es una clase parcial de Editor. Genera escena, prefabs, materiales, audio y referencias serializadas; modificar sus fuentes y reconstruir, sin editar YAML a mano.
- Runtime en `Assets/Scripts`, assembly `Crater`. Componentes MonoBehaviour, referencias explícitas, UnityEvents y coroutines. Nombres y documentación en español.
- Coordenadas del nivel en mundo; las alas se construyen antes de trasladarse (-3,0,11)/(3,0,11). El valle usa coordenadas locales y queda encima de la Explanada.
- Test Framework 1.6.0: EditMode para mecánicas, PlayMode para recorrido real. `ValidarProyectoCrater` valida referencias y alcance.
- Puente local autorizado e instalado: `com.unity.pipeline 0.8.0-exp.1`. Unity CLI conectado al Editor de este proyecto; runtime del puente desactivado para builds. Editor instalado en `C:/Program Files/Unity/Hub/Editor/6000.3.23f1/Editor/Unity.exe`. No abrir otro Editor batch sobre el mismo proyecto mientras esté abierto.
- Fuente del alcance: resumen adjunto de cambios y transcripción aportada de Spatial Communication in Level Design. No reincorporar mirillas, portales, surcos, miguitas, ventanas de retorno ni zigzag descartados.
- Validación visual del valle y de la Cresta requiere capturas o recorrido en Unity; la compilación por sí sola no confirma esas vistas.
